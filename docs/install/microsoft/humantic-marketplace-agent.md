# The Humantic AI agent from the Microsoft Marketplace

[Back to Microsoft Copilot](README.md)

You may have installed **Humantic AI** from the Microsoft Marketplace, or your admin did. It gives Copilot a connection to Humantic AI, so Copilot can read a person, research an account and pull buying signals.

## What it does and does not include

| | In the Marketplace agent |
| :--- | :--- |
| The connection to Humantic AI | Yes |
| The seven sales skills | **No** |

## Why you cannot add the skills to it

An agent you install from the Marketplace belongs to its publisher. Nobody who installs it can add or change its skills. Microsoft's guidance to publishers today is not to ship custom skills inside an agent package, so Humantic AI cannot add them there either. This page will change when Microsoft opens that up.

## You can still have both

Pick one of the two routes. Both give you the skills and the Humantic AI connection.

### Route 1: Use the skills in Copilot Cowork

This is the quickest. Keep the Humantic AI agent as it is. Add the skills next to it.

1. Follow [Install in Copilot Cowork](cowork.md).
2. In a new Cowork session, ask for what you need, for example `prep me for my meeting with Acme tomorrow`.

### Route 2: Build your own agent with both

This gives you one agent you control, with the skills and the Humantic AI connection together.

1. Follow [Install in Copilot Studio](copilot-studio.md) from the top.
2. In Step 3 of that page, connect Humantic AI to your agent.

Your agent then does what the Marketplace agent does, and also follows the seven skills.

## Which route should you pick?

| You want | Pick |
| :--- | :--- |
| The fastest route, for yourself | Route 1 |
| One agent for the team, in Microsoft Copilot and Teams | Route 2 |
| To manage who gets it, centrally | Route 1, rolled out by your admin with [Admin rollout](admin-rollout.md) |
