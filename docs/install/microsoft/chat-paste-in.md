# Use the skills in one Copilot Chat

[Back to Microsoft Copilot](README.md)

Copilot Chat cannot reliably open links, so you paste the skill itself. This works today with no install and no admin. It lasts for that one chat.

1. Open the skill you want in the [skills](../../../skills) folder, then open its `SKILL.md`.
2. Select the **Copy raw file** button at the top right of the file.
3. Start a new Copilot Chat.
4. Type the two lines in the block below.
5. Paste the skill underneath them.
6. Send it. Copilot confirms in one line.
7. Ask for what you need.

```text
Below is a skill definition. Follow it for the rest of this conversation.
Reply with one line to confirm, then ask me what you are working on.

[open a skill in the skills folder of this repo, copy all of it,
and paste it here]
```

Repeat from step 1 for each skill you want in that chat.

## When you want it to stay

- For yourself, use [Copilot Cowork](cowork.md).
- For an agent you control, use [Copilot Studio](copilot-studio.md).
- For your whole company, send your admin the [admin rollout](admin-rollout.md) page.
