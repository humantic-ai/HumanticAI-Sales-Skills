# Install in Microsoft Copilot

"Copilot" is several different products from Microsoft. Each one installs skills in a different way. Find yours first, then open its page.

[Back to all assistants](../../../INSTALL.md)

## Which one do you use?

| You use | What it is | Go to |
| :--- | :--- | :--- |
| **Copilot Cowork** | Microsoft 365 Copilot, with a **+** and **Customize** in the message box | [Copilot Cowork](cowork.md) |
| **Copilot Studio** | You build your own agent at copilotstudio.microsoft.com | [Copilot Studio](copilot-studio.md) |
| **The Humantic AI agent** | You installed Humantic AI from the Microsoft Marketplace | [Humantic AI agent](humantic-marketplace-agent.md) |
| **Copilot Chat** with **Agent Builder** | You build agents inside Copilot Chat | [Agent Builder](agent-builder.md) |
| **Copilot Chat**, plain | A chat window, no agents | [Use them in one chat](chat-paste-in.md) |
| **A Microsoft 365 admin** | You want to roll the skills out to everyone | [Admin rollout](admin-rollout.md) |

## Which skills route fits which job?

| You want | Best route |
| :--- | :--- |
| All seven skills for yourself, fastest | [Copilot Cowork](cowork.md) |
| All seven skills inside an agent you control, with Humantic AI connected | [Copilot Studio](copilot-studio.md) |
| All seven for the whole company, nothing for people to install | [Admin rollout](admin-rollout.md) |
| To try a skill once, with no setup | [Use them in one chat](chat-paste-in.md) |

## One thing to know about the Humantic AI agent

The Humantic AI agent from the Microsoft Marketplace carries the connection to Humantic AI. It does not carry the seven skills, and you cannot add skills to it yourself. The page [Humantic AI agent](humantic-marketplace-agent.md) shows the two ways to get both.

## Connect Humantic AI

The skills work without Humantic AI. They get much sharper with it. To connect it, follow the Microsoft Copilot steps in [the setup guide](../../setup-humantic.md#microsoft-copilot).

## Check it worked

1. Start a new chat, or a new Cowork session.
2. Type: `Prep me for my meeting with [a colleague's LinkedIn URL] tomorrow.`
3. Send it.

**It worked if** you get the outcome the meeting has to produce, a read on the person, questions to ask and the ask. **It did not work if** you get a general answer with none of that. Go back over the steps on your page.
